1. Dirección visual general

---

Mantener una estética clara, editorial y profesional.

Paleta:

* Violeta principal: #351C75
* Violeta suave: #EEE5FF
* Base: blanco / off-white
* Texto: negro suave / gris oscuro
* Bordes: grises suaves
* Verde: solo para disponibilidad

Reglas:

* El violeta debe ser acento, no color dominante.
* No hacer una web completamente morada.
* No hacer una web completamente dark.
* Usar #EEE5FF solo como detalle suave, no como fondo excesivo.
* Mantener una estética con aire, jerarquía clara y buen ritmo visual.
* Evitar exceso de chips, badges, sombras o decoraciones.

La estética debe ser más editorial que SaaS.
Debe sentirse como el portfolio de una Product Designer, no como una landing comercial.

10. Imágenes y placeholders

---

Por ahora, donde vaya una imagen real, dejar un recuadro gris sobrio.

Requisitos del placeholder:

* fondo gris claro o gris medio suave
* borde sutil
* mismo radius que las cards/imágenes del sistema
* mantener proporción y tamaño del bloque visual
* no romper layout
* no mostrar íconos innecesarios
* no mostrar wireframes falsos
* no mostrar mockups inventados
* no mostrar imágenes generadas
* no mostrar skeletons decorativos
* no dejar imágenes rotas

Texto opcional dentro del recuadro:
Imagen pendiente

Si se usa texto, debe ser chico, discreto y centrado.

Objetivo:
Reservar claramente el espacio donde luego voy a cargar imágenes reales, sin que el placeholder parezca una imagen final ni compita visualmente con el contenido.

Aplicar en:

* hero si hay espacio de imagen
* proyectos destacados
* páginas de detalle
* sección conocimiento si corresponde
* cualquier bloque donde esté prevista una imagen real

Cuando cargue imágenes reales más adelante, esos placeholders se reemplazarán.
